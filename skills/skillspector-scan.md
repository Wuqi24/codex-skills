# skillspector-scan

**EN**: Offline, evidence-driven, auditable security scanner for AI agent skills: read-only scan for prompt injection, data exfiltration, supply-chain, dangerous code calls, and 16+ risk categories. Features: brief mode (facts + inference), verified records, Inspection Ledger, Docker container scanning, cloud CI scanning, and rule-pair fixtures (72 regression tests).
